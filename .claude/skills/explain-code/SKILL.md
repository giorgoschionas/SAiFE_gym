When explaining code, always include:

1. **Analogies**: When I am asking to explain mathematical formulas in my Python implementation of Uniswap v3, I want you to draw the comparison with real implementation of Uniswap v3 or any relevant reference in the whitepaper of Uniswap v3. For example, if I am asking about the formula for calculating the value of a position in a certain range, I want you to explain how this formula is derived from the Uniswap v3 whitepaper and how it relates to the actual implementation of Uniswap v3.

2. **Conversational explanations**: Keep explanations conversational. For complex concepts, use multiple analogies.
