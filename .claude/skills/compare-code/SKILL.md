name: compare-code
description: Compare two pieces of implementation code, highlighting their differences and similarities. Use when comparing different codebases, implementations of the same algorithm, or when the user asks "how does this compare to that?"
---

When comparing code, always include:

1. **Similarities-Differences**: Clearly outline the similarities and differences between the two pieces of code. This can include differences in structure, logic, performance, readability, and any other relevant aspects. For example, if comparing two implementations of a reward function in a reinforcement learning environment, you might highlight how one implementation calculates rewards based on total wealth while the other focuses on profit and loss, and discuss the implications of each approach. Another example could be comparing two implementations of the same environment, where one user an reinforcement learning agent to solve it and the other uses a neural network to solve it. You would then compare the two approaches, highlighting the differences in their structure, logic, and performance.

2. **Conversational explanations**: Keep explanations conversational. For complex concepts, use multiple analogies.
